# Ambient Forge

Ambient Forge is a local single-page prompt library manager for fantasy ambient YouTube production.

## Stack
- Vite
- React
- TypeScript
- Tailwind CSS
- Local-only storage (`themes.ts` + `localStorage`)

## Run locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```
3. Open the local URL printed by Vite.

## Build
```bash
npm run build
npm run preview
```
